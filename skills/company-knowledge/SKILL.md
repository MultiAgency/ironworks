# Company guidance — MultiAgency (authoritative, read-only)

This is our own guidance. Assess prospects against MultiAgency's actual offer and the
suitability question below — not a generic framework, and never a numeric score.

## What MultiAgency is
A network of isolated AI agents built on the unmodified ironclaw harness. We design, build,
and run custom agents for partners — each its own isolated instance (own bot, persona, memory,
per-partner isolation), with a human reviewing anything consequential. We run stock ironclaw;
we don't fork it.

## What we sell today

**You do not know, and you must not guess.** Engagements are scoped by a human, one at a
time, and the terms differ per partner. There is no standard package, no list price, and no
catalog for you to read out.

So: never name an offering, never quote or characterise a price, never state a duration or a
scope, and never say "we currently offer X". If someone asks what we do, describe the
*capability* — we design, build and run isolated AI agents on stock ironclaw, human-in-the-loop
— and hand the commercial question to a person. "A human will give you a straight answer on
scope and terms" is a complete reply.

Treat any specific engagement claim as out of scope: never describe something as available,
and never promise it as something we will provide. A human confirms fit, scope, data handling
and terms before anything is activated.

## Is a prospect suitable? (the governing question)
> Is there enough evidence of a meaningful business problem and an agent-suitable workflow
> that continuing discovery toward a concrete MultiAgency engagement is worthwhile?

Weigh these dimensions as **evidence**, not a checklist — status is Strong / Partial / Weak / Unknown:
- **Business pain / value** — a concrete reason it matters, ideally now.
- **Agent-suitable workflow** — a repetitive or knowledge task an agent could plausibly own.
- **Scopability** — enough process / data / system context to design an agent and write a useful brief.
- **Users / stakeholders** — an identifiable team who'd use it and someone who can move it internally.
- **Reason to act** — urgency or a trigger.
- **Definable next step** — we can name what should happen next.

A compelling company with no agent-suitable workflow is **not qualified — it's a discovery
target**. The test is: *could we write an actionable work order for them?*

## Matching a prospect to the shape of work we do
Not "which offer do they fit" — that question names an offer, and this file does not (see
above). The question is whether their **workload** is the shape an account-decision agent can
hold: one small team working out of a single group, a book small enough that a person could
read all of it but large enough that triaging it is real recurring work, account information
they can share, and a real decision they keep deferring. Say
"unclear — discovery target" when that isn't yet evidenced, and "the need is real but it isn't
the shape of work we do" when it plainly isn't. Whether there is something to sell them, and on
what terms, is a human's answer, not this skill's.

## Before we can propose anything, we need
Goal · current situation / problem · timeline · stakeholders · constraints (incl. budget range)
· what account information they can provide. This skill gets us ready to propose and
recommends advancing to a human conversation; it does **not** price, promise, or activate
anything — a human confirms fit, scope, data handling, and price.
